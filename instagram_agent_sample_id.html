Bab 01 dari 07
Pengenalan & Arsitektur
Gratis Dibaca

Panduan ini mendokumentasikan cara membangun Instagram content agent yang sepenuhnya otomatis — menghasilkan postingan menggunakan AI, mengupload gambar, dan mempublish ke Instagram dan Facebook tanpa perlu kamu sentuh setiap harinya. Tidak butuh latar belakang coding. Setiap error yang mungkin kamu temui sudah didokumentasikan beserta solusi tepatnya.

Apa yang Dilakukan Agent

Setiap hari pada waktu yang sudah dijadwalkan, agent berjalan di server GitHub dan menyelesaikan 5 langkah secara otomatis — tanpa kamu perlu melakukan apapun. Ini yang terjadi:

1
Cek Token
Memverifikasi bahwa Meta access token kamu masih valid. Auto-refresh jika akan habis dalam 5 hari — kamu tidak pernah kehilangan akses.
2
Pembuatan Konten via Claude AI
Memanggil Claude API untuk menulis postingan lengkap — hook, caption, slide carousel, 30 hashtag, dan image prompt. Bahasa bergantian antara Bahasa Indonesia dan Inggris sesuai hari.
3
Pipeline Gambar
Mengambil gambar cover dari Unsplash (gratis), lalu menguploadnya ke Cloudinary untuk mendapatkan URL publik yang bisa diakses oleh API Meta.
4
Publish ke Instagram
Mempublish ke Instagram via Meta Graph API resmi — single image atau carousel tergantung hari dalam seminggu.
5
Cross-Post ke Facebook
Opsional — cross-post konten yang sama ke Facebook Page kamu secara bersamaan, menjangkau kedua audiens sekaligus.

Technology Stack

Setiap layanan yang digunakan dalam panduan ini gratis atau biayanya kurang dari harga satu kopi per bulan. Ini yang berjalan di balik layar:

ℹ️

Claude API — menghasilkan caption, slide, dan hashtag. Biaya: sekitar Rp15.000–75.000/bulan dengan 1 postingan per hari. Top-up Rp75.000 bisa bertahan beberapa bulan.

✅

Unsplash + Cloudinary + GitHub Actions + GitHub Pages — semuanya sepenuhnya gratis. Nol biaya hosting, nol server, nol biaya bulanan.

⚠️

Meta Graph API — gratis tapi ada batas 25 postingan/hari. Dengan 1 postingan/hari kamu tidak akan pernah mencapai batas ini. Saat testing setup mungkin kamu kena — reset setiap pukul 07:00 WIB.

Strategi Konten — 12 Pilar, 2 Bahasa

Agent tidak hanya posting sembarangan. Ia mengikuti strategi konten terstruktur dengan 12 pilar yang berputar — 5 topik evergreen dan 7 pilar krisis yang dirancang khusus berdasarkan dampak ekonomi perang Iran-AS Juni 2026 terhadap Indonesia.

7 pilar krisis mencakup: Bertahan di Krisis, Lindungi Uangmu, Investasi di Tengah Krisis, Rupiah Melemah, Hidup Hemat Saat Inflasi, Mindset Pemenang, dan Dampak Harga Minyak. Semuanya berdasarkan angka nyata — Rp18.000/USD, inflasi 4,76%, tekanan anggaran Rp500T — membuat konten terasa berwibawa dan aktual, bukan generik.

# Logika pergantian bahasa — dari content.py def get_language() -> str: iso_day = datetime.now().isoweekday() # 1=Sen … 7=Min return "Bahasa Indonesia" if iso_day % 2 == 1 else "English" # Hasilnya: # Senin, Rabu, Jumat, Minggu → 🇮🇩 Bahasa Indonesia # Selasa, Kamis, Sabtu → 🌐 English

Yang Akan Kamu Miliki Setelah Menyelesaikan Panduan Ini

Di akhir Bab 7, setup kamu akan terlihat seperti ini — dua repositori GitHub yang melakukan semua pekerjaan untukmu:

instagram-agent/ (Repo Private) ├── agent berjalan harian via GitHub Actions ✅ ├── posting Bahasa Indonesia + Inggris ✅ ├── promosikan 15 platform afiliasi ✅ └── auto cross-post ke Facebook Page ✅ links/ (Repo Publik — GitHub Pages) └── halaman bio link bilingual yang cantik ✅ di-host gratis di github.io/links/

Jadwal posting harian sudah dikonfigurasi ke waktu Jakarta (WIB) dan posting pada jam engagement tertinggi — 07:00, 09:00, 12:00, 18:00, atau 19:00 tergantung harinya. GitHub Actions cron jobs menangani semuanya secara otomatis. Kamu hanya perlu check-in setiap 60 hari untuk me-refresh Meta access token — dan bahkan itu pun bisa diotomasi.
