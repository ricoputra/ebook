Pengenalan & Arsitektur

Panduan ini mendokumentasikan cara membangun Instagram content agent yang sepenuhnya otomatis — menghasilkan postingan menggunakan AI, mengupload gambar, dan mempublish ke Instagram & Facebook setiap hari tanpa kamu perlu melakukan apapun. Tidak butuh latar belakang coding. Setiap error yang mungkin kamu temui sudah didokumentasikan beserta solusi tepatnya.

Apa yang Dilakukan Agent

Setiap hari pada waktu yang sudah dijadwalkan, agent berjalan di server GitHub dan menyelesaikan 5 langkah secara otomatis — tanpa kamu perlu melakukan apapun:

1
Cek Token
Memverifikasi bahwa Meta access token kamu masih valid. Auto-refresh jika akan habis dalam 5 hari — kamu tidak pernah kehilangan akses.
2
Pembuatan Konten via Claude AI
Memanggil Claude API untuk menulis postingan lengkap — hook, caption, slide carousel, 30 hashtag, dan image prompt. Bahasa bergantian antara Bahasa Indonesia dan Inggris sesuai hari.
3
Pipeline Gambar
Mengambil gambar unik untuk setiap slide dari Unsplash (gratis), lalu menguploadnya ke Cloudinary untuk mendapatkan URL publik yang bisa diakses oleh API Meta.
4
Publish ke Instagram
Mempublish ke Instagram via Meta Graph API resmi — single image atau carousel tergantung hari dalam seminggu.
5
Cross-Post ke Facebook
Opsional — cross-post konten yang sama ke Facebook Page kamu secara bersamaan, menjangkau kedua audiens sekaligus.

Technology Stack

Setiap layanan yang digunakan dalam panduan ini gratis atau biayanya kurang dari harga satu kopi per bulan:

ℹ️

Claude API — menghasilkan caption, slide, dan hashtag. Biaya: sekitar Rp15.000–75.000/bulan dengan 1 postingan per hari. Top-up Rp75.000 bisa bertahan beberapa bulan.

✅

Unsplash + Cloudinary + GitHub Actions + GitHub Pages — semuanya sepenuhnya gratis. Nol biaya hosting, nol server, nol biaya bulanan.

⚠️

Meta Graph API — gratis tapi ada batas 25 postingan/hari. Dengan 1 postingan/hari kamu tidak akan pernah mencapai batas ini. Saat testing setup mungkin kamu kena — reset setiap pukul 07:00 WIB.

Strategi Konten — 17 Pilar, 2 Bahasa

Agent tidak hanya posting sembarangan. Ia mengikuti strategi konten terstruktur dengan 17 pilar yang berputar — 5 evergreen, 5 AI money, dan 7 pilar krisis berdasarkan dampak ekonomi perang Iran-AS Juni 2026 terhadap Indonesia.
